# 🎓 Student ID Card Generator

A beginner-friendly Python project that generates a formatted student ID card template in the terminal.

## ✨ Features

- Formatted student ID card layout
- Student, course, branch, batch and contact fields
- Terminal colors using Colorama
- Placeholder/demo data for privacy
- Jupyter Notebook version
- Standalone Python script

## 🛠️ Technologies

- Python 3
- Colorama
- Jupyter Notebook

## 📁 Project Structure

```text
student-id-card-generator/
├── Main Code.ipynb
├── main.py
├── requirements.txt
├── README.md
├── .gitignore
├── LICENSE
└── preview.txt
```

## 🚀 Run the Project

### Install the dependency

```bash
pip install -r requirements.txt
```

### Run the Python file

```bash
python main.py
```

### Run the notebook

Open `Main Code.ipynb` in Jupyter Notebook or JupyterLab and run the code cell.
